CONTEXTO DO PROJETO:
Sistema de gestão de salão de beleza com uma tela de Agenda 
que exibe os horários e agendamentos do dia.

PROBLEMA IDENTIFICADO PELO CLIENTE:
Ao acessar a tela de Agenda, o conteúdo está aparecendo 
deslocado para o lado direito da tela em vez de ficar 
centralizado. O cliente quer que o conteúdo fique 
centralizado horizontalmente.

TAREFA — implemente as seguintes mudanças:

1. Localize o componente/página da Agenda no projeto.

2. Identifique a causa do deslocamento para a direita — 
   verifique se é causado por:
   - margin/padding incorretos
   - flexbox ou grid mal configurado
   - width/max-width ausente ou errado
   - offset causado por sidebar ou menu lateral

3. Corrija o layout para que o conteúdo da agenda fique 
   centralizado horizontalmente na tela.

4. A correção deve funcionar em:
   - Desktop (telas largas)
   - Mobile (telas pequenas, como celular)

5. Não altere o conteúdo visual da agenda (horários, 
   cards de agendamento, cabeçalho), apenas o 
   posicionamento/layout do container principal.

ATENÇÃO:
- Não altere nenhuma outra tela além da Agenda.
- Não altere estilos globais que possam impactar 
  outras páginas do sistema.
