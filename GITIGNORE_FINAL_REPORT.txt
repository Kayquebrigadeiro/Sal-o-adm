🚀 INSTRUÇÕES PARA O BACKEND EM NODE.JS
════════════════════════════════════════════════════════════════════════════

POR FAVOR LEIA ANTES DE FAZER COMMIT:

1. NUNCA faça commit com arquivo .env contendo dados reais
   ❌ ERRADO: git add .env
   ❌ ERRADO: Copiar valores reais em .env.example
   ✅ CERTO: Usar .env.example apenas como referência

2. ANTES DE FAZER COMMIT, verifique:
   └─ git status
   └─ git diff --cached --name-only
   └─ Confirme que NÃO há .env ou arquivos sensíveis

3. SE ACIDENTALMENTE FAZ COMMIT com .env:
   └─ REGENERE TODAS AS CREDENCIAIS (muito importante!)
   └─ Use: git filter-branch ou BFG Repo-Cleaner
   └─ Faça force push para remover do histórico

4. CONFIGURAR CREDENCIAIS EM PRODUÇÃO:
   └─ Render: Environment Variables no painel
   └─ Vercel: Environment Variables no painel
   └─ Local: Arquivo .env (não commit)
