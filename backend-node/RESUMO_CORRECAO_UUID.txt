🐛 PROBLEMA ENCONTRADO
─────────────────────────────────────────────────────────────────────────────
  Várias rotas usavam result.insertId para obter UUIDs gerados pelo banco.
  Isso NÃO funciona: insertId só funciona com AUTO_INCREMENT.
  
  Resultado: Chaves primárias recebiam 0 em vez de UUID válido
  Impacto: Violação de foreign keys, falhas de transação

🔧 SOLUÇÃO IMPLEMENTADA
─────────────────────────────────────────────────────────────────────────────
  1. Instalar biblioteca uuid: npm install uuid
  2. Gerar UUIDs em JavaScript ANTES do INSERT
  3. Passar coluna 'id' explicitamente na query INSERT
  4. Usar a variável gerada, não result.insertId

📊 COMPARAÇÃO: ANTES vs DEPOIS
─────────────────────────────────────────────────────────────────────────────

ANTES (❌ Errado):
─────────────────
  const [salaoResult] = await connection.query(
    'INSERT INTO saloes (nome, ...) VALUES (?, ...)',
    [nome_salao, ...]
  );
  const salao_id = salaoResult.insertId;  // ❌ Retorna 0 para UUID!
  
  await connection.query(
    'INSERT INTO configuracoes (salao_id, ...) VALUES (?, ...)',
    [salao_id, ...]  // ❌ salao_id = 0 -> Viola FK!
  );

DEPOIS (✅ Correto):
────────────────────
  const salao_id = uuidv4();  // ✅ Gera UUID em JavaScript
  
  const [salaoResult] = await connection.query(
    'INSERT INTO saloes (id, nome, ...) VALUES (?, ?, ...)',
    [salao_id, nome_salao, ...]  // ✅ Passa UUID explicitamente
  );
  
  await connection.query(
    'INSERT INTO configuracoes (salao_id, ...) VALUES (?, ...)',
    [salao_id, ...]  // ✅ salao_id é UUID válido!
  );
